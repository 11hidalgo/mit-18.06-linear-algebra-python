# mit-18.06-linear-algebra-python
Implementación desde cero y mediante NumPy/SciPy de los algoritmos fundamentales del curso 18.06 del MIT (Gilbert Strang): descomposición PA=LU, proyecciones ortogonales, regresión por mínimos cuadrados, Gram-Schmidt, autovalores/autovectores y compresión de imágenes mediante SVD, validados con tests unitarios en Pytest.
